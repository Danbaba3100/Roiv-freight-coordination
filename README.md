# Roiv Freight Coordination

Professional, responsive website for Roiv Freight Coordination, LLC — a nationwide truck dispatch service based in Cheyenne, Wyoming.

## Project status
Initial website scaffold is being prepared. The company logo and final brand colors will be added when supplied.

## Local preview
Open `index.html` in a browser, or run a local static server from the project root.

## SEO foundations
- Page-specific titles and meta descriptions
- Semantic headings and internal links
- Canonical URLs
- XML sitemap and robots.txt
- Local business structured data using the supplied business details

## Important
Confirm the public production domain before launch and update canonical URLs, sitemap URLs, and structured data accordingly. Do not publish placeholder testimonials, unsupported claims, or fabricated business credentials.
